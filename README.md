### About

**[RedTeam Subnet](https://github.com/RedTeamSubnet/RedTeam)** — a decentralized
cybersecurity platform on Bittensor where miners compete on offensive and

---

### What I work on

**Bot detection & device fingerprinting**
Behavioral signal extraction — timing patterns, browser property consistency,
rendering behaviour — plus headless/automation detection and VPN identification,
validated against millions of production requests.

**Browser automation at scale**
A YAML-configured framework running 8 driver stacks (Playwright, Selenium,
SeleniumBase, Nodriver, Camoufox and others) to generate labeled bot traffic
for detection model training.

**Backend systems**
Concurrency-safe scoring pipelines handling 100+ parallel requests with isolated
per-request state, LLM-based code evaluation platforms, and structured data
processing pipelines.

**Infrastructure**
CI/CD with GitHub Actions, Dockerized microservices behind NGINX, and monitoring
and log aggregation stacks (Uptime Kuma, Fluent Bit, Loki, Grafana).

**Code review**
I review the majority of pull requests across our codebase — enforcing quality
standards and catching regressions before they reach production.
